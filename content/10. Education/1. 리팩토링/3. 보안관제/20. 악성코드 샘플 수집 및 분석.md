# 악성코드 샘플 수집 및 분석
## 악성 샘플 수집
![[Pasted image 20251210210719.png]]

악성 코드의 네트워크 동작이 잘 나타나 있는 ANY RUN에서 adware를 검색하여 나타나는 악성 코드 중 네트워크 동작이 많은 Adobe_Acrobat_msetup_aVkyy.exe 샘플을 사용했습니다. 해당 샘플의 해쉬 값은 아래와 같습니다.

- **MD5:** 502db3fdcb1f401bab3247411e506457
- **SHA-1:** 502db3fdcb1f401bab3247411e506457
- **SHA-256:** e4e9c9cefed88c575143b93d946d2258cdd4d041b6addb5fb29ba3f0931311b7

## 기초분석
### VirusTotal
VirusTotal에 다운받은 샘플 파일을 업로드하여 결과를 확인했습니다.

![[Pasted image 20251210210743.png]]

Threat categories를 살펴보면 에드웨어, 트로이목마, 다운로더 계열의 악성코드라는 것을 확인할 수 있습니다.

### VirusTotal - Details
![[Pasted image 20251210210802.png]]

악성 샘플의 파일 타입은 Win32 EXE로 윈도우즈 환경에서 실행할 수 있습니다. 또한 악성 파일은 2022/11/29에 생성되었습니다. 그리고 패킹관련 정보가 보이지 않으므로 패킹되어있지 않은 파일로 보여집니다.

### VirusTotal - Relations
![[Pasted image 20251210210815.png]]

"[http://mpcrow.org](http://mpcrow.org/)"라는 URL이 반복적으로 등장하고 Detections를 확인해보면 악성 행위가 감지되므로 해당 URL과 연관되어 있으며 해당 URL을 통해 악성 행위가 일어남을 예상할 수 있습니다.

하지만 Contacted Domains항목의 "mpcrow.org" 도메인의 생성일이 2022-09-06이며 해당 악성 파일의 생성일이 2022-11-29입니다. 또한 Contacted URLs 항목의 "mpcrow.org"관련 URL들의 Scanned 날짜를 확인해보면 관련된 URL들이 2022년 11월부터 23년 7월까지만 스캔된 것을 확인할 수 있습니다.

따라서 해당 악성 샘플의 네트워크를 통한 악성 행위가 현재 분석 환경에서도 동일하게 일어날 가능성은 낮아 보입니다.

![[Pasted image 20251210210844.png]]

마지막으로 Contacted IP addresses 항목을 확인해보면 "13.107.12.4.50", "239.255.255.250" IP 주소와 관련되어 있을 것이라고 예상할 수 있습니다.

### VirusTotal - Behavior
![[Pasted image 20251210210903.png]]

Network comms(Network Communications) 항목을 보면 76개의 네트워크 활동이 탐지된 것을 확인할 수 있습니다.

### Packing 유무
#### Exeinfo PE
![[Pasted image 20251210210927.png]]

#### PEView
![[Pasted image 20251210211059.png]]

파일의 맨 앞 바이트를 확인해보면 MZ(4D5A)로 파일은 PE(Portable Executable) 파일 포멧이라는 것을 확인할 수 있습니다.

![[Pasted image 20251210211111.png]]

IMAGE_FILE_HEADER를 살펴보면 기초분석에서 확인한 것과 동일하게 파일이 2022/11/29에 생성된 것을 확인할 수 있습니다.

![[Pasted image 20251210211120.png]]

파일의 확장자가 .text, .rdata, .data, .rsrc, .reloc로 변형되지 않은 것과 Virtual Size와 Size of Raw Data의 값이 거의 일치하는 것으로 보아 패킹되어 있지 않다는 것을 확인할 수 있습니다.

![[Pasted image 20251210211129.png]]

IMPORT Directory table에서는 Bintext에서 확인한 아스키 코드로 인코딩된 부분에서 확인했던 DLL파일 목록을 확인할 수 있습니다. 유니코드로 인코딩된 DLL파일들은 리스트에 들어있지 않았습니다. 따라서 무조건 PEView만 확인하여 import된 DLL파일 목록을 확인하는 것보다 Bintext로 크로스 체크하는 것이 좋습니다.

## 동적분석
![[Pasted image 20251210211153.png]]

Windows 7 Home Premium K 64bit 환경에서 Windows 7 서비스 스택 “kb4474419”, “kb4490628”을 업데이트한 후 악성 파일을 바탕화면 디렉토리에 두고 관리자 권한으로 실행하여 분석했습니다.

### 파일 실행
![[Pasted image 20251210211210.png]]

실행한 후 왼쪽 다음 버튼을 눌렀습니다. 체크박스는 조작하지 않고 기존의 설정된 값으로 진행했습니다.

![[Pasted image 20251210211217.png]]

다음 버튼을 눌렀습니다. 마찬가지로 체크박스는 조작하지 않았습니다.

![[Pasted image 20251210211224.png]]

이 화면에서는 Adobe Acrobat과 이전 화면에서 체크한 파일들의 설치가 진행됩니다. 제가 진행했던 테스트 환경에서는 setup.exe가 올바른 Win32 응용 프로그램이 아니라는 오류 메시지와 DLL파일의 스크립트 오류가 발생했습니다.

### ProcessExplorer
consent.exe와 dllhost.exe가 순간 실행되었다가 사라지는 것을 관측하였습니다.

### 네트워크 행위 분석
![[Pasted image 20251210211302.png]]

SmartSniff를 살펴보면 cdn2.msetup.pro라는 도메인과 패킷을 교환한 것을 확인할 수 있습니다.

![[Pasted image 20251210211312.png]]

해당 도메인을 VirusTotal을 통해 분석해보면 96개 중 1개의 엔진에서 악성 행위를 탐지한 도메인으로 해당 도메인을 통해서 악성 행위가 일어날 가능성이 있음을 확인했습니다.

![[Pasted image 20251210211321.png]]

CurrPorts를 통해서 당시 해당 IP주소로 연결이 수립되어 있던 프로세스 아이디가 3396라는 것과 도메인의 서버 IP주소가 88.208.5.115.80 임을 확인했습니다.

![[Pasted image 20251210211329.png]]

Process Explorer로 당시의 프로세스 상황을 기록하여 3396의 PID를 가진 프로세스가 뭔지 확인한 결과 Adobe_Acrobat_msetup_aVkyy.exe라는 것을 확인했습니다. 하지만 Process Monitor를 통해 해당 IP와 관련된 Operation을 찾아내지 못했습니다.

#### WireShark
WireShark로 해당 IP와 주고받은 패킷을 살펴보았습니다. 먼저 TCP Connection이 정상적으로 수립되고 GET, POST등 API를 호출하는 것을 볼 수 있었습니다. 또한 Client에서 데이터를 요청하여 해당 서버에서 데이터를 전송해주는 것도 확인할 수 있습니다.

### Autoruns
![[Pasted image 20251210211442.png]]

악성 파일을 실행하기 전의 스냅샷과 실행 후의 스냅샷을 Autoruns을 통해 비교했지만 변경을 탐지하지 못했습니다.

### System Explorer
![[Pasted image 20251210211501.png]]

해당 악성코드는 Adobe Acrobat 및 다른 여러 파일들을 설치하므로 악성 행위를 하는 파일을 찾기에는 어려움이 있어 파일을 찾지 못했습니다.

## Snort
Adobe_Acrobat_msetup_aVkyy.exe에서 88.208.5.115와 패킷을 주고받고 있으므로 해당 패킷을 탐지하는 룰을 구성해보면 아래와 같습니다.
- alert tcp any any -> 88.208.5.115 any (msg: ”Malicious Packet Detection - IP 88.208.5.115”; sid:1000001;)
- alert tcp 88.208.5.115 any -> any any (msg: ”Malicious Packet Detection - IP 88.208.5.115”; sid:1000002;)

![[Pasted image 20251210211550.png]]

위의 룰을 등록하고 Snort를 실행한 상태에서 Adobe_Acrobat_msetup_aVkyy.exe를 실행한 결과 BASE에서 TCP 패킷이 탐지된 것을 확인할 수 있습니다.

![[Pasted image 20251210211601.png]]

또한 주고받은 실제 패킷을 살펴보면  88.208.5.115.80이 Source와 Destination 주소에 찍혀있는 것을 확인할 수 있습니다.

## 아쉬운 점
- Process Monitor에서 Adobe_Acrobat_msetup_aVkyy.exe 프로세스의 악성 행위를 식별하지 못했습니다. 양이 너무 방대하여 필터를 사용했지만 키워드 선정의 잘못인지 아니면 실제로 동작이 기록되지 않았는지 네트워크 기록은 보였지만 API 기록은 찾지 못했습니다.
