# 정탐, 오탐, 미탐, 악성코드 유형
## 악성 코드란?
Malware라고 부르고 정상적인 기능을 하기 위한 코드가 아닌, 사용자에게 해악을 끼치는 등 악의적인 목적을 가지고 만들어진 모든 코드를 통칭해서 악성 코드라고 합니다.

## 악성 코드 탐지 구분
악성 코드를 탐지하는 것을 정탐, 오탐, 미탐으로 구분합니다.

|       | Positive       | Negative       |
| ----- | -------------- | -------------- |
| True  | True Positive  | True Negative  |
| False | False Positive | False Negative |
위의 표를 살펴보면 True, False는 탐지의 성공 유무를 나타냅니다. 만약 True일 경우 해당 파일의 속성을 정확하게 탐지했다는 것이됩니다.(정상적 파일을 정상이라고 판단) False일 경우 해당 파일의 속성과 반대로 탐지했다는 것입니다.(정상적 파일을 악성코드라고 판단)  
Postive와 Negative는 탐지한 대상의 속성을 나타냅니다. Positive는 문제가 없는 정상적인 파일을 말하며 Negative는 악성 코드가 존재하는 비정상적인 파일을 나타냅니다. 

정탐은 True Positive, True Negative인 경우를 말하며  
오탐은 False Positive인 경우를,  
미탐은 False Negative를 나타냅니다.

즉,  
정탐(TP, TN)은 정상적으로 탐지한 경우  
오탐(FP)은 탐지를 했지만 잘못 탐지한 경우  
미탐(FN)은 탐지조차 안한 경우를 말합니다.

좀 더 자세하게 살펴보겠습니다.

**정탐(TP, TN)**  
**True Positive** - 정상적인 것을 정상으로 탐지한 경우(문제가 없는 파일에서 문제를 탐지하지 않은 경우)  
**True Negative** - 비정상적인 것을 비정상이라고 탐지한 경우(문제가 있는 파일에서 문제를 탐지한 경우)

**오탐(FP)**  
**False Positive** - 정상적인 것을 비정상으로 탐지한 경우(문제가 없는 파일에서 문제를 탐지한 경우)

**미탐(FN)**  
**False Negative** - 비정상적인 것을 정상으로 생각하여 탐지조차 안한 경우

### False Positive, False Negative
오탐(FP)의 경우 잘못탐지하더라도 탐지가 된다면 원인을 분석하여 추후 수정을 통해 좀 더 나아진 탐지가 가능하지만  
미탐(FN)의 경우 분석조차 할 수 없기에 시스템이 무방비해집니다.

따라서 미탐률을 줄이는 것이 매우 중요합니다.

## 악성코드 유형
### 바이러스(Computer Virus)
바이러스라고도 하며, 생물학적 바이러스가 다른 세포 속에 들어가 그 세포를 악성세포로 만들듯, 컴퓨터 바이러스는 정상적인 프로그램과 코드를 악성코드로 만들며 스스로를 복제하여 컴퓨터 소프트웨어 전체에 전파됩니다.

바이러스는 크게 부트 영역을 감염시키는 부트(boot) 바이러스와 본래 숙주 프로그램에 감염되었다가 그 기능을 수행하는 숙주 바이러스로 구분됩니다.

**사례**  
**13일의 금요일 바이러스**

1980~90년대에 유행했던 바이러스로 실행되면 COM, EXE파일을 감염시킨 후 13일 금요일의 0~24시동안 작동되며 해당 날짜에 감염된 파일을 실행한 후 다른 실행 파일들을 실행하면 파일을 지웁니다.

### 웜(Warm)
여러 단말기에 분산되어 퍼져 그 단말기들이 연결된 네트워크 전체를 감염시킵니다.  
일반적인 바이러스와 달리 네트워크를 사용하여 스스로 복사본을 전파할 수 있으며 자기 복제를 이용하여 네트워크를 손상시키고 파일 등을 악의적으로 암호화합니다.

**사례**  
**블래스터 웜**  
2000년대 초에 유행했던 악성코드로 아래와 같이 "60초 후 컴퓨터가 종료됩니다"라는 팝업창을 띄운 후 컴퓨터가 종료되는 증상이 했습니다.

### 트로이 목마(Trojan Horse)
그리스 로마 신화에 나오는 트로이 목마에서 유래한 이름을 가진 악성코드로 밖으로 드러난 목적과 다르게 동작하거나 시스템 안에 잠복해 있다가 특정 조건이 성립하면 악성 행위를 시작합니다.

백도어 기능을 가지고 있기도 하며 웜이나 바이러스처럼 자기 복제는 하지 않는 것이 기본이지만 최근에는 대다수의 악성코드가 트로이 목마를 전제로 웜과 바이러스의 기능을 동시에 가지고 있기 때문에 이들을 칼같이 구분하지는 않습니다.

**사례**
**V3RES Trojan**
도스 시절 V3의 램 상주형 백신인 V3RES를 사칭하는 트로이 목마로 V3RES가 정상적으로 램에 상주된 것처럼 보이는 더미 화면을 출력하고 현재 실행된 드라이브의 모든 디렉토리 안에 V3RES.COM(트로이 목마) 파일을 복제해 넣었습니다.

### 백도어(Backdoor)
백도어는 뒷문이라는 뜻으로 하드웨어나 소프트웨어 등의 개발과정이나 유통과정 중에 몰래 탑재되어 정상적인 인증 과정을 거치지 않고 보안을 해제할 수 있도록 만드는 악성코드입니다.

만약 서버에 백도어가 심어져 있다면 매번 권한 상승을 할 필요 없이 높은 권한을 가지게 됩니다.

**사례**  
**중국 CCTV**  
대한민국 육군이 중국에서 납품받은 CCTV에서 중국쪽 서버로 영상이 전송되는 악성코드를 발견한 경우가 있습니다.

### 다운로더(Downloader)
다른 악성코드를 다운로드할 목적으로만 사용되는 악성코드로 실행되면 단순히 외부 서버에서 악성코드를 다운로드 해주는 역할을 합니다.

**사례**  
**NanoCore RAT**  
키로깅, 스크린샷, 캡쳐, 웹캠 제어, DDoS, 웹 브라우저 및 이메일, FTP 클라이언트 계정 정보 수집과 같은 다양한 기능을 지원하는 바이러스로 스팸 메일을 통해 사용자가 첨부파일을 다운로드하여 실행하면 감염됩니다.

### 드로퍼(Dropper)
드로퍼는 악성행위를 수행할 파일을 자기 자신 안에 숨겨두고 해당 프로그램이 실행됐을 때 숨겨둔 악성 파일을 시스템에 설치하고 실행시킵니다.

### 루트킷(Rootkit)
Root권한으로 접속해서 악성행위를 할 수 있게 해주는 소프트웨어의 집합을 의미하며 자기 자신의 존재를 은닉시키도록 설계됐기 때문에 피해자는 루트킷을 쉽게 탐지할 수 없으며 이를 이용해 공격자의 접속 정보나 로그 등을 지워 타겟이 공격당하고 있음을 눈치채지 못하게 하기도 합니다.

**사례**  
**AbstractEmu**  
안드로이드 악성코드로 앱에 포함되어 설치된 후 시스템 정보를 수집하고 외부로 전송하는 기능을 가지고 있습니다.

또한 루트 액세서를 통해 트로이 목마가 SMS로 전송된 2단계 인증 코드를 수신하거나, 백그라운드에서 실행하고, 피싱 공격을 시작하는 데 사용하는 공통 권한을 공격자에게 부여하기도 합니다.

### 스파이웨어(Spyware)
spy와 software를 합성한 단어로 스파이처럼 컴퓨터에서 정보를 수집해 공격자한태 전달해주는 악성코드입니다. 어떤 소프트웨어를 설치할 때 같이 설치되기도 합니다.

공격자는 이 정보를 사용자의 동의 없이 유출하거나 판매할 수도 있습니다.  
키로거, 스니퍼, 패스워드 해시 수집기 등이 여기에 해당됩니다.

**사례**  
**페가수스 스파이웨어**  
iOS와 안드로이드에 설치될 수 있는 이스라엘의 NSO 그룹이 개발한 스파이웨어로 문자 메시지 읽기, 전화 추적, 비밀번호 수집, 위치 추적, 장치 마이크 카메라 접근, 앱 정보 가져오기를 수행 가능합니다.

### 애드웨어(Adware)
스파이웨어와 유사하게 어떤 소프트웨어를 설치할 때 같이 설치되기도하며 광고 노출만을 목적으로 하는 악성코드입니다.

### 스케어웨어(Scareware)
이름에서 알수 있듯이 사용자를 겁주는 악성코드로 보통 실질적인 악성 행위를 하진 않지만 사용자를 겁줘 공격자가 원하는 행위를 수행하도록 합니다.
