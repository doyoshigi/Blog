# 동적분석, 정적분석
## 정적분석
정적분석이란 의심되는 파일을 실행하지 않고 파일 자체가 가지고 있는 내용을 분석해서 악의적인 코드가 있는지 확인하는 방식이다.

### 정적분석 방법
- 파일의 해시값을 확인하여 원본 파일의 해시값과 비교한다. 다르면 변조된 파일이다.
- 해시값을 Virustotal에 검색하여 결과를 살펴본다.
- 악성 코드가 사용하는 문자열을 확인한다.
- 악성 코드 실행 파일에 저장된 리소스를 분석한다.

## 정적분석 도구
### Exeinfo PE
![[Pasted image 20251209231500.png]]

- 파일의 패킹 여부를 확인한다.
- 해당 파일이 어떤 툴로 패킹을 했는지 파악이 가능하다.
	- 패킹이 되어있지 않을 경우 어떤 언어로 컴파일 되었는지 확인이 가능하다.

### PE View
![[Pasted image 20251209231640.png]]

## 동적분석
정적분석이란 의심되는 파일을 직접 실행하여 나타나는 변화들을 모니터링 해 분석하는 방법이다.
악의적인 행위를 할 가능성이 있는 파일을 실행하는 것이기에 가상 샌드박스 환경에서 실행해야 한다.

### 동적분석 방법
- Vmware, VirtualBox와 같은 툴로 가상 환경을 구축하여 관리자 권한으로 의심되는 파일을 실행한다.
- 생성되는 프로세스, 레지스트리, 파일 변화를 확인하고 네트워크 동작을 확인한다.
