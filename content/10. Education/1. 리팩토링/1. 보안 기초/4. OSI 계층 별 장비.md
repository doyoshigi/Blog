# OSI 계층 별 장비
## 1계층 (물리 계층) 장비

### 케이블 (Cable)
- 물리적으로 전기 신호를 전송합니다.

### 리피터 (Repeater)
- 전기신호의 증폭을 담당하는 장비입니다.
- 케이블 전송으로 약화된 신호를 초기화, 증폭, 재전송하는 기능을 수행합니다.
- 상위 계층에서 사용하는 MAC 주소, IP 주소를 이해하지 못합니다.

### 허브 (Hub, L1)
- 리피터와 마찬가지로 전기적 신호를 증폭시킵니다.
- LAN의 전송 거리를 연장시키고 여러 대의 장비를 LAN에 접속할 수 있도록 합니다.(멀티 포트 리피터)
- 포트가 여러 개이며 전달받은 패킷을 접속해 있는 모든 노드로 전달합니다.(플러딩)
- 위의 특성 때문에 충돌이 많이 발생하기 때문에 허브에 많은 장비를 연결할 수 없습니다.
- 허브에 연결된 장비들은 하나의 충돌 도메인에 있습니다.

>[!note] 충돌이란?
>허브는 수신한 데이터를 연결되어 있는 모든 포트에 수신하므로 허브의 여러개의 포트에서 동시에 신호가 수신된다면 신호가 부딪혀서 충돌이 일어나게 됩니다.  
>이런 충돌이 발생할지도 모르는 범위를 충돌 도메인(Collision Domain)이라고 합니다.

## 2계층 (데이터 계층) 장비
### 브릿지 (Bridge)
- 같은 네트워크의 장비를 연결하는 장치입니다.
- 허브와 마찬가지로 Ethernet 장비를 물리적으로 연결하고 Frame의 전송거리를 연장합니다.
- 전기적 신호만 증폭시키는 것이 아니라 Frame을 다시 만들어서 전송합니다.
- 허브와 다르게 2계층 주소인 MAC 주소를 보고 Frame 전송 포트를 결정합니다.

### 스위치 (Switch, L2)
- 허브와 마찬가지로 Ethernet 장비를 물리적으로 연결하고 Frame의 전송거리를 연장합니다.
- 브릿지와 스위치는 MAC 주소와 해당 장비의 포트 번호가 기록된 MAC 주소 테이블을 보고 해당 목적지에만 Frame을 전송합니다.
- 브릿지와 마찬가지로 전기적 신호만 증폭시키는 것이 아니라 Frame을 다시 만들어서 전송합니다.
- 스위치는 한 포트에 전송되는 Frame이 MAC 주소 테이블에 있는 특정 포트로만 전송하기 때문에 다른 포트가 전송하는 Frame과 충돌이 발생하지 않습니다.
- 스위치는 각각의 포트가 하나의 충돌 도메인에 있습니다.

#### 브릿지와 스위치
**공통점**
- MAC 주소 테이블을 보고 특정 포트로만 프레임을 전송합니다.
- 리피터의 기능과 프레임을 만들어서 전송합니다.

**차이점**
- 스위치는 하드웨어적으로 처리하고 브릿지는 소프트웨어적으로 처리합니다. 따라서 스위치의 속도가 훨씬 빠릅니다.
- 브릿지에 있는 포트들은 모두 같은 속도를 지원합니다. 스위치는 서로 다른 속도로 연결할 수 있습니다.
- 스위치는 브릿지 보다 포트의 수가 많습니다. 브릿지는 채 10개도 되지 않습니다.
- 스위치는 cut-through 또는 store-and-forward 방식을 사용하지만 브릿지는 store-and-forward 방식만 사용할 수 있습니다.

**store-and-forward**
- 패킷이 들어오면 전부 받아들인 다음 처리를 시작합니다.
- 패킷을 받고 무결성을 체크합니다. 만약 무결한 데이터가 아니라면 재전송을 요청합니다.

**cut-through**
- 패킷의 목적지 주소만(패킷의 처음 6바이트)을 보고 전송 처리를 시작합니다.
- store-and-forward 방식과는 달리 에러 핸들링이 부족합니다.

## 3계층 (네트워크 계층) 장비
### 라우터 (Router, L3)
- 서로 다른 네트워크를 연결합니다.
- 라우터의 기본 기능은 경로 설정과 정해진 경로에 따라 패킷을 전송하는 것입니다.
- 그리고 라우터의 추가 가능은 네트워크 보안과 QoS입니다.
    - 여기서 QoS란 네트워크 상에서 모든 사용자들이 쾌적하게 네트워크 서비스를 이용할 수 있도록 자원을 분배하는 기능입니다. 네트워크상에 흐르는 데이터의 중요도를 분류하여 우선순위가 높은 것을 더 안전하고 빠르게 처리합니다.
- 특정 인터페이스를 통해 수신한 패킷의 목적지 IP 주소를 보고 목적지와 연결된 인터페이스를 통해 전송을 결정합니다. 이를 라우팅(Routing)이라고 합니다.
- 라우터와 L3 스위치는 IP주소 등 Layer 3 Header에 있는 주소를 참조하여 목적지와 연결되는 포트로 패킷을 전송합니다.
    - 따라서 L3 스위치와 라우터를 Layer 3장비라고 합니다.

### 동적 라우팅, 정적 라우팅
**정적 라우팅(Static Routing)**
- 네트워크 관리자가 라우팅 테이블에 수동으로 정책을 구성하는 방법입니다.
- 네트워크 구성이 변경되어도 정적 라우팅 정책이 적용된 경로는 변하지 않습니다.

장점
- 라우터 CPU에 오버헤드가 없습니다.
- 네트워크 관리자가 라우팅 동작을 제어할 수 있기에 예측 가능하여 보안상 더 유리합니다.  
단점
- 네트워크 규모가 커질수록 관리하기 어려워집니다.
- 수동으로 설정하는 것이기에 네트워크 관리자의 역량에 따라 문제가 발생할 수 있습니다.
- 네트워크 구성 변경에 따른 기존 라우팅 경로가 제대로 동작하지 않을 경우 경로가 재구성되기 전까지 트래픽을 처리할 수 없습니다.

**동적 라우팅(Dynamic Routing)**

- 시스템 내 네트워크의 현재 구성에 맞게 최적의 경로를 찾아서 데이터를 전송하는 방식입니다.
- end to end 간 통신에 손상이 발생할 경우 선택 가능한 다른 경로를 통해 통신할 수 있어 시스템의 내결함성을 가질 수 있습니다.

장점

- 네트워크 관리자의 라우팅 정책 유지를 위한 작업 소요가 적습니다.
- 네트워크 구성과 상황에 맞게 최적의 경로를 설정할 수 있습니다.
- 경로 손실이 발생하더라도 자동으로 경로를 변경하여 통신할 수 있습니다.  
 단점
- 다른 많은 장비들과 통신하기 위해서 정적 라우팅에 비해 많은 대역폭 소비가 발생합니다.

## 4계층 (전송 계층) 장비
### 로드 밸런서 (Load Balancer, L4)
- 서버나 장비의 부하를 분산하기 위해 사용하는 장비입니다.
- 트래픽을 분배해주는 기능과 IP주소나 4계층의 정보, 어플리케이션 정보를 확인, 수정하는 기능이 있습니다.
- 주로 웹 서버 부하 분산에 사용됩니다.

### 방화벽 (Firewall)
- 네트워크 중간에서 해당 장비를 통과하는 트래픽을 주어진 정책 조건에 따라 허용하거나 차단하는 장비입니다.

## 7계층 (애플리케이션 계층) 장비
### L7 스위치
- Layer 3~7에 속하는 IP 주소, 포트 정보, 패킷 내용 등의 모든 정보를 확인하고 스위칭을 해주는 장비입니다.
- L4의 로드 밸런싱과는 다르게 더 자세한 정보를 확인하기 때문에 보안에 더 유리하게 정교한 로드 밸런싱이 가능합니다.
