# 구글 해킹, Google Hacking(Dorking)
## 구글 해킹이란?
구글 해킹(Google Hacking/Dorking)이란 구글의 고급 검색 연산자(advanced search operator)를 활용하여 일반적인 검색으로는 쉽게 드러나지 않는 정보를 인터넷에서 찾아내는 기법입니다.

이 전략은 구글 알고리즘의 기능을 활용해 특정한 문자열을 포함한 결과를 탐색할 수 있도록 해줍니다.

'해킹'이라는 단어가 있어 불법적인 활동으로 보이지만 구글 해킹 자체는 합법적인 활동이며 보안 전문가들이 자사 시스템 내 보안 취약점을 식별하고 점검하기 위해 사용하는 방법이기도 합니다.

## 구글 해킹이 어떻게 작동하는가?
구글 해킹은 고급 검색 연산자를 활용하여 검색 결과를 정밀하게 필터링하고 특정 정보를 정확히 찾아내는 방식입니다. 이러한 연산자들은 키워드나 문자열과 함께 사용하면, 구글 검색 알고리즘에 특정 조건의 정보를 찾아달라고 명령할 수 있습니다.

예를 들어, 특정 파일 형식만 검색하거나, 특정 웹 사이트 내부만 탐색하거나, 웹 페이지 제목에 포함된 특정 단어를 찾거나, 특정 URL로 연결되는 링크를 포함한 페이지를 찾아낼 수 있습니다.

구글 해킹은 구글이 크롤링을 통해 접근 가능한 모든 웹 페이지를 색인화(indexing)한다는 점을 이용합니다. 즉, 웹 상에 공개된 정보라면 누구나 접근 가능하다는 점을 악용하거나 활용하는 셈입니다.

구글 해킹을 통해 민감한 정보가 노출되는 경우도 있지만, 이는 해당 정보가 이미 공개적으로 접근 가능한 상태일 경우에 한하며, 이 기법 자체는 법률이나 구글의 서비스 이용 약관을 위반하지 않습니다.

## 대표적인 키워드
advanced search operator의 대표적인 키워드를 설명하겠습니다.

### 1. Filetype
![[Pasted image 20251211120831.png]]

특정 파일 형식을 검색할 때 사용합니다.
'filetype:pdf'는 PDF 파일만 검색 결과로 보여줍니다.

### 2. Inurl
![[Pasted image 20251211120842.png]]

URL 내에 특정 단어가 포함된 페이지를 찾습니다.
'inurl:login'은 URL에 'login'이 포함된 페이지를 찾습니다.
하위 url까지 검색할 수 있습니다.

### 3. Intext
![[Pasted image 20251211120855.png]]

웹 페이지의 본문 내용 중 특정 단어가 포함된 페이지를 검색합니다.
'intext:"password"'는 "password"라는 단어가 본문에 포함된 페이지를 찾아냅니다.
구글의 일반적인 검색에서 키워드를 사용하지 않아도 기본적으로 포함되어 있는 키워드입니다.

### 4. Intitle
![[Pasted image 20251211120911.png]]
![[Pasted image 20251211120917.png]]

웹 페이지의 제목(title)에 특정 단어가 포함된 경우를 찾습니다.
'intitle:"index of"'는 디렉토리 목록이 공개된 웹 서버를 탐지할 때 자주 사용됩니다.

### 5. Link
![[Pasted image 20251211120934.png]]

특정 URL을 링크하고 있는 외부 웹 페이지를 찾을 수 있습니다.
'link:example.com'은 example.com으로 연결된 페이지들을 보여줍니다.

### 6. Site
![[Pasted image 20251211120946.png]]

특정 사이트 내부에서만 검색을 수행할 때 사용합니다.
'site:example.com'은 해당 도메인 내부의 콘텐츠만 검색합니다.
inurl과 달리 대표 url만 검색됩니다.

## 구글 해킹의 위험성
구글 해킹은 강력한 정보 수집 도구이지만, 악용될 경우 심각한 위험을 초래할 수 있습니다. 이 기법은 실수로 공개된 민감한 정보를 노출시킬 수 있으며 이는 심각한 개인정보 침해로 이어질 수 있습니다. 예를 들어, 악의적인 공격자는 구글 해킹을 이용해 보호되지 않은 데이터베이스, 서버 인증 정보, 내부 문서 등을 찾아낼 수 있습니다.

또한 구글 해킹은 웹 사이트 인프라의 보안 취약점을 드러낼 수 있기 때문에 해당 사이트가 사이버 공격의 표적이 될 가능성도 있습니다. 실제로 해커들이 이 기법을 활용해 보안 허점을 식별하고, 익스플로잇(exploit)을 개발하거나 타깃 공격을 감행하는 사례가 많습니다. 결과적으로 이는 데이터 유출, 신원 도용, 사이버 스파이 활동, 기타 다양한 사이버 범죄에 악용될 수 있습니다.

## 구글 검색을 통해 찾을 수 있는 취약점
### 1. 관리자 페이지 노출
![[Pasted image 20251211121023.png]]
![[Pasted image 20251211121027.png]]

- 'intitle:"admin login"'
인증 없이 접속 가능한 관리자 페이지를 찾을 수 있습니다. 웹 방화벽 설정이 없거나 기본 계정이 그대로 사용되는 경우 위험합니다.

관리자한태만 보여지고 접근되어야 하는 페이지가 일반 사용자에게 보여진다는 것은 해커, 공격자도 접근이 가능하다는 것입니다. 이는 무차별 대입 공격(brute-force) 공격에 노출될 수 있습니다.

### 2. 백업 및 설정 파일 노출
![[Pasted image 20251211121056.png]]

- 'filetype:bak', 'fietype:sql', 'filetype:xml', 'filetype:env'

데이터베이스 백업, 설정 파일, 환경 변수 파일 등이 유출되면 내부 시스템 정보가 노출될 수 있습니다.

### 3. 로그 파일 및 오류 메시지
![[Pasted image 20251211121127.png]]
![[Pasted image 20251211121132.png]]

- 'filetype:log', 'inurl:error.log'
경로, 시스템 구조, IP 주소, 관리자 활동 기록 등이 노출될 수 있습니다.

### 4. 계정 정보 및 비밀번호가 포함된 파일
![[Pasted image 20251211121150.png]]

- 'filetype:xls intext:password', 'filetype:txt intext:login'
사내 공유용 문서에 로그인 정보가 포함돼 있을 수 있습니다. 실수로 웹 루트에 업로드 된 경우 검색으로 노출될 수 있습니다.

### 5. 카메라/IoT 장비의 웹 인터페이스
![[Pasted image 20251211121204.png]]
![[Pasted image 20251211121210.png]]

- 'inurl:view/view.shtml'
인증 없이 접속 가능한 웹캠, CCTV 등 IoT 장비 제어 화면에 접근 가능합니다.

### 6. 디렉토리 인덱싱이 켜진 서버
![[Pasted image 20251211121228.png]]

- 'intitle:"index of /admin"'
서버 측에서 디렉토리 목록을 숨기지 않아 전체 파일 목록이 보이는 경우가 있습니다. 여기에 설정 파일이나 로그, 소스코드 등이 포함돼 있다면 큰 위협이 될 수 있습니다.

### 7. 프린터, 라우터, NAS 등 네트워크 장비 설정 페이지
![[Pasted image 20251211121238.png]]

- 'inurl:8080 intitle:"web config"'
기본 계정에서 변경하지 않거나 암호 설정을 안 한 장비가 검색됩니다.

## 구글 해킹 침해를 예방하는 방법
### 1. 민감한 정보 노출 제한
민감한 정보는 온라인에 공유하지 않아야 합니다. 불가피하게 공유해야 할 경우에는, 검색 엔진에 색인되지 않도록 설정하고 접근 제어를 철저히 구성해야 합니다.

### 2. robots.txt 파일 사용
robots.txt 파일을 이용해 검색 엔진 크롤러에게 어떤 페이지를 탐색할지 무시할지를 지시합니다.

민감한 디렉토리나 파일이 검색되지 않도록 robots.txt를 구성해야 합니다.

### 3. 'noindex', 'nofollow' 태그 활용
\<meta\>에 noindex, nofollow 속성을 활용해 특정 페이지가 검색 결과에 노출되지 않도록 설정할 수 있습니다.  
  

### 4. 정기적인 웹 사이트 보안 점검
정기적인 보안 점검을 통해 노출된 정보나 잠재적인 취약점을 조기에 발견하고 대응할 수 있습니다. 구글 해킹을 이용해 자사 시스템을 테스트해 보는 것도 유용한 보안 진단 방법입니다.

### 5. 파일 및 디렉토리 권한 제한
파일과 디렉토리에 대한 접근 권한을 최소한으로 설정합니다.

필요하지 않은 공개 권한은 제거하고, 민감한 경로에 대한 접근은 반드시 통제되어야 합니다.

### 6. 보안 도구 및 방화벽 사용
웹 애플리케이션 방화벽(WAF) 등 보안 도구를 통해 비정상적인 접근을 실시간으로 모니터링 하고 차단함으로써 구글 해킹 시도를 방어할 수 있습니다.
