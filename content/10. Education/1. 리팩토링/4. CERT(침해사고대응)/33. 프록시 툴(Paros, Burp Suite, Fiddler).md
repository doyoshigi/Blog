# 프록시 툴(Paros, Burp Suite, Fiddler)
## Paros
![[Pasted image 20251212203208.png]]

Paros(파로스)는 웹 취약점 분석(XSS, SQL Injection 등)용으로 설계된 Java기반 오픈소스 웹 프록시 도구입니다.

HTTP/HTTPS 트래픽 분석 및 간단한 스캐닝 기능이 제공됩니다.

2000년대 초반에 많이 사용되었으나 2008년 이후 업데이트가 중단되었습니다. 따라서 신뢰성과 안전성이 확인되지 않기에 많이 사용되지 않습니다.

**장점**
- 오픈소스이며 가볍습니다.
- 최소한의 기능만 있어 입문제에게는 직관적입니다.

**단점**
- 개발 중단으로 최신 환경에서는 제대로 동작하지 않을 수 있습니다.
- 다른 툴과 비교했을 때 기능이 제한적입니다.

## Burp Suite
![[Pasted image 20251212203232.png]]

Burp Suite(버프슈트)는 PortSwigger에서 개발한 상용 웹 보안 테스트용 프록시 도구입니다.
HTTP/HTTPS 트래픽 분석, 수정, 리플레이, 자동화 스캐너 등 강력한 기능을 제공합니다.
무료, 유료 버전이 존재합니다.

**장점**
- 가장 많이 사용되는 웹 보안도구 중 하나로 다양한 플러그인 생태계가 형성되어 있습니다.
- 최신 HTTPS 프로토콜에 완벽 대응합니다.
- 웹 보안 분석에 특화된 기능들이 많습니다.

**단점**
- 무료 버전은 자동 스캔과 같은 일부 기능이 제한됩니다.
- UI가 복잡하여 초보자에겐 러닝커브가 존재할 수 있습니다.

## Fiddler
![[Pasted image 20251212203249.png]]

Fiddler(피들러)는 Telerik(Progress Software)에서 개발한 HTTP/HTTPS 디버깅 프록시 도구입니다.
주로 개발자(특히 프론트 엔드, 모바일)들이 애플리케이션을 개발하는 과정에서 HTTP 트래픽을 디버깅하는 용도로 많이 사용합니다. 또한 홈페이지에 대한 위변조 공격을 확인하기 위해서도 사용합니다.
Windows환경에서 사용이 편리하며 .NET 기반 환경과도 잘 통합됩니다.

**장점**
- UI가 직관적입니다.
- 웹/모바일 앱의 트래픽 분석에 최적화되어 있습니다.
- 무료 버전도 강력합니다.

**단점**
- 보안 취약점 분석 용도로는 기능이 제한적입니다.
- 자동화 스캔, 페이로드 테스팅 등의 보안 관련 기능이 없습니다.
