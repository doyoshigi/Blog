# 사물인터넷과 Shodan
## 사물 인터넷이란?
사물 인터넷(IoT, Internet of Things)이란 각종 사물에 센서와 통신 기능을 내장하여 인터넷에 연결하는 기술입니다. 다시 말해서 사물여러가지 전자기기에 네트워크 주소가 생긴 것을 말합니다.

## 사물 인터넷 예시
### 스마트 홈캠
![[Pasted image 20251211122332.png]]

스마트폰 앱을 통해 실시간으로 집 안을 모니터링하고, 저장된 영상을 확인할 수 있는 가정용 CCTV입니다.

육아, 반려동물, 보안 등의 용도로 사용합니다.

### AI스피커
![[Pasted image 20251211122340.png]]

인공지능 기술을 이용하여 음성 명령을 이해하고 음악 재생, 정보 검색, 다른 IoT 기기 제어 등 다양한 기능을 수행하는 스피커입니다.

### 스마트 도어락
![[Pasted image 20251211122355.png]]

비밀번호 입력 방식 뿐만아니라 카드키, 지문인식, 스마트폰을 통한 원격 잠금/해제, 출입 기록 확인, 스마트 홈 연동 등의 기능이 있는 도어락입니다.

## Shodan(쇼단)
![[Pasted image 20251211122405.png]]

쇼단은 인터넷에 연결된 기기들을 찾아주는 검색 엔진입니다.

Shodan은 대표적인 OSINT(Open-Source Intelligence) 도구 중 하나로 인터넷에 연결된 기기(웹캠, CCTV, 라우터, IoT기기 등)에 대한 정보를 수집합니다.

## Shodan 크롤러
쇼단의 크롤러는 전 세계의 IP 주소를 끊임없이 스캔합니다. 그리고 각 기기들이 인터넷과 소통하기 위해 열어놓은 포트(Port)를 통해 **배너(Banner) 정보를 수집**합니다.

**배너란?**
배너란 특정 포트에 접속했을 때 해당 서비스가 자신을 식별하기 위해 보내주는 일종의 '자기소개' 정보입니다.

서비스 종류에 따라 배너에는 소프트웨어 이름, 버전 정보, 운영체제 등 다양한 내용이 포함됩니다.

배너는 서버나 호스트가 아니라 '서비스'에서 나오기 때문에 HTTP 서비스, FTP 서비스, SNMP 서비스 등 여러 개의 서비스를 가진 한 개의 장비에서 다양한 배너들이 나타날 수 있습니다.

또한 쇼단에서 볼 수 있는 정보들은 기기의 소유자나 제 3자가 스푸핑했거나 오래된 정보일 수 있으므로 쇼단의 검색 결과를 맹신해선 안됩니다.

## Shodan 검색 방법
![[Pasted image 20251211122420.png]]

사이트에 로그인을 한 후 검색 필터에 검색어를 입력하여 검색하면 검색된 기기의 배너 정보를 볼 수 있습니다.

![[Pasted image 20251211122431.png]]

검색된 기기를 클릭하면 포트, 도메인, 국가, 호스트 이름, ISP 등의 상세 정보를 확인할 수 있습니다.

## 검색 필터
쇼단은 좀 더 구체적인 검색을 위한 검색 필터(Search Filter)라는 키워드가 있습니다.

**지리적 위치 관련 필터**
- country
    - 특정 국가에 있는 기기를 검색합니다.
    - e.g. country:KR
- city
    - 특정 도시에 있는 기기를 검색합니다.
    - e.g. city:Seoul
- geo
    - 특정 위도와 경도를 기준으로 검색합니다.
    - e.g. geo: 37.5665,126.9780,50(서울 시청 기준으로 반경 50km이내의 기기)

**네트워크 관련 필터**
- net
    - 특정 주소 범위(CIDR)에 있는 기기를 검색합니다.
    - e.g. net: 8.8.4.4
- port
    - 특정 포트가 열려 있는 기기를 검색합니다.
    - e.g. port:80
- isp
    - 특정 인터넷 서비스 제공업체(isp)에 속한 기기를 검색합니다.
    - e.g. isp:"Korea Telecom"
- org
    - 특정 기관이나 회사 이름으로 검색합니다.
    - e.g. org:"Google LLC"
- asn
    - 특정 자율 시스템 번호(ASN)에 속한 기기를 검색합니다.
    - e.g. asn:AS15169

**운영체제, 소프트웨어 관련 필터**
- os
    - 특정 운영체제를 사용하는 기기를 검색합니다.
    - e.g. os"Windows 10"
- product
    - 특정 소프트웨어 제품 이름을 검색합니다.
    - e.g. product:"Apache httpd"
- version
    - 특정 소프트웨어 버전을 검색합니다.
    - e.g. product:"Apache httpd" version:"2.4.58"

**이 외에도 수많은 검색 필터가 존재하며 아래의 링크에서 확인할 수 있습니다.**
[https://www.shodan.io/search/filters](https://www.shodan.io/search/filters)

## 보안에서의 활용
**Attack Surface 관리**
쇼단을 통해 어떤 정보가 노출되어 있는지 파악하여 불필요하게 열려있는 포트, 과도하게 노출되어 있는 서비스 등을 확인하고 이를 최소화합니다.

**취약점 관리**
product, version, os, vuln 등의 필터를 활용하여 오래된 버전의 소프트웨어를 사용하거나 알려진 보안 취약점(CVE)을 가진 기기들을 식별합니다. 또한 기본 비밀번호를 사용하는 기기를 찾아내어 설정을 강화하도록 조치할 수 있습니다.

CCTV, 웹캠, IP카메라 등이 노출될 경우 개인의 프라이버시가 침해될 수 있으며 만약 카메라가 특정 회사의 출입 금지 구역이나 지역을 비추고 있을 경우 회사의 기밀성을 훼손시킬 수 있습니다.

또한 AI 스피커, 공유기, NAS 등의 내부에 여러 기능이 내장되어있고 파일이나 데이터가 저장되는 기기들이 외부 공격자에게 노출된다면 내부 정보가 유출될 수 있습니다.

IoT 기기들이 외부에 노출되어 있다 하더라도 계정 아이디, 비밀번호를 변경했다면 괜찮지만 대부분 기본 아이디, 비밀번호를 사용하거나 123450처럼 쉬운 값으로 설정하는 경우가 많아 IoT 기기를 사용한다면 꼭 기본 계정, 비밀번호를 변경해야 합니다
