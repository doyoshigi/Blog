# Shodan 실습
## 쇼단을 통해 검색 가능한 대표적인 IoT기기
### 1. CCTV(Closed-Circuit Television)
CCTV는 이름에서 알 수 있듯이 닫힌 회로 안에서만 작동하기에 인터넷과 분리되어 있어 과거에는 쇼단으로 기기를 검색할 수 없었습니다. 하지만 CCTV를 스마트폰과 같은 외부 기기에서 확인하기 위해 DVR(Digital Video Recorder)를 통해 인터넷에 연결하거나 인터넷 연결 기능을 지원하는 CCTV를 사용할 경우 쇼단에 검색되며 취약점이 노출될 수 있습니다.

**취약점**
쇼단을 통해서 찾을 수 있는 CCTV의 취약점은 아래와 같습니다.
- 관리자 페이지 기본/쉬운 비밀번호 사용
- 알려진 보안 취약점(CVE)이 있는 펌웨어 사용
- 원격 접속 포트 노출

### 2. Web Cam
웹캠은 주변 기기로 USB 케이블이나 노트북 자체에 내장된 형태로 컴퓨터에 연결되어서 작동하는 기기입니다. 웹캠 자체는 인터넷에 직접 연결되지 않으며 웹캠이 연결된 호스트 컴퓨터(PC 혹은 노트북)가 인터넷에 연결됩니다. 따라서 쇼단을 통해 찾아야 하는 것은 웹캠 자체가 아니라 웹캠이 연결된 호스트 컴퓨터입니다.

**취약점**
- 호스트 컴퓨터에 RAT(Remote Access Trojan, 원격 제어 악성코드)가 감염되면 공격자는 악성코드를 통해 PC의 모든 권한을 획득하고 웹캠에 접근하여 사생활 침해가 발생할 수 있습니다.
- 컴퓨터의 원격 데스트톱(RDP, Remote Desktop Protocol) 기능이 허술한 비밀번호로 설정된 채 인터넷에 노출될 경우 공격자가 이를 쇼단으로 찾아내고 원격으로 접속하여 웹캠을 제어할 수 있습니다.

### 3. IP Cam
IP 카메라는 독립적인 컴퓨터로 자체적인 CPU, 메모리, 네트워크 통신 기능이 모두 내장되어 있는 기기입니다. 따라서 웹캠과 달리 컴퓨터 없이도 스스로 작동하고 인터넷에 접속할 수 있습니다.

**취약점**
- 관리자 페이지 기본/쉬운 비밀번호 사용
- 알려진 보안 취약점(CVE)이 있는 펌웨어 사용
- 영상 데이터를 전송하는 RTSP(Real Time Streaming Protocol) 포트가 인증 절차 없이 열려있는 경우 해당 주소만 알면 누구나 영상을 볼 수 있습니다.
- 영상 데이터나 괸라자 페이지 접속 정보가 암호화되지 않은 채 전송되어 스니핑 공격에 취약할 수 있습니다.

### 4. Network Printer
네트워크 프린터는 네트워크에 연결되어 여러 사람이 함께 공유해서 사용할 수 있습니다. IP 카메라처럼 네트워크 프린터도 내부에 작은 컴퓨터를 내장하고있어 스스로 네트워크 통신이 가능합니다.

회사에서 내부망과 외부망 프린터를 분리하지 않고 단일하게 사용할 경우 프린터는 내부망과 외부망의 경계에 위치해 있을 가능성이 높습니다. 그렇다면 해당 프린터는 인터넷에 연결되어 있으므로 공격자는 프린터를 통해 업무망에서 사용하는 문서에 접속할 수 있으며 기업 정보 유출 가능성이 있습니다.

**취약점**
- 관리자 페이지 기본/쉬운 비밀번호 사용
- 프린터와 PC간 전송되는 인쇄 데이터가 암호화 되지 않은 경우, 공격자가 중간에서 스니핑할 수 있습니다.
- 관리자 계정이 탈취되면 프린터의 저장공간에 저장된 문서가 유출될 수 있습니다.
- 프린터가 사용하는 특정 포트가 외부 인터넷에 무방비로 열려있는 경우 공격자가 이 포트로 임의의 인쇄 명령을 보낼 수 있습니다.
- 알려진 보안 취약점(CVE)이 있는 펌웨어 사용

### 5. 산업제어시스템(ICS, Industrial Control System)
ICS란 발전소, 전력망, 상하수도 시설, 공장, 교통 시스템 등 국가의 중요 기반 시설과 산업 공정을 자동으로 감시하고 제어하는 컴퓨터 시스템을 말합니다. 과거 ICS는 외부와 완전히 분리된 폐쇄망에서 운영되었지만 효율성과 편의성을 위해 점점 인터넷에 연결되는 부분들이 생기고 있습니다.

ICS의 예로는 SCADA, DCS, PLC 등이 있습니다.

SCADA(Supervisory Control And Data Acquistion)는 중앙 통제실에서 넓은 지역에 분산된 설비들을 원격으로 감시하는 제어하는 시스템입니다.
DCS(Distributed Control System)는 특정 공장이나 시설 내부의 복잡한 공정들을 제어하는 분산된 시스템입니다.
PLC(Programmable Logic Controlller)는 현장의 밸브, 모터, 센서 등 개별 장비에 직접 연결되어 정해진 논리에 따라 기기를 제어하는 소형 컴퓨터입니다.

**취약점**
- ICS 장비 간 통신에 사용되는 프로토콜은 과거 폐쇄망을 가정하고 만들어져 별도의 인증이나 암호화가 없는 경우가 많습니다. 이를 이용해 공격자는 공장 라인을 멈추거나 밸브를 조작하여 화학 물질을 유출시키는 등 비정상적인 조작을 할 수 있습니다.
- 원격 관리 인터페이스 화면이 인터넷에 그대로 노출되는 경우
- 제어 장비에 기본/쉬운 비밀번호 사용
- 제어 장비의 알려진 보안 취약점(CVE)이 있는 펌웨어 사용
