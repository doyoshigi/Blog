# DVWA 실습 환경 구성
## KALI LINUX 설치
데미안 기반 모의 침투 테스트용 운영체제인 칼리 리눅스를 설치합니다.
칼리 리눅스는 버프 슈트 등과 같은 모의 해킹에 자주 사용되는 소프트웨어들이 설치된 상태로 배포되기 때문에 Windows 환경에서 DVWA를 설치하는 것 보다 편리하여 칼리 리눅스로 환경을 구성했습니다.

![[Pasted image 20251212203807.png]]

하단의 링크로 접속하여 VMWare 버전으로 다운로드 합니다.
[Get Kali | Kali Linux](https://www.kali.org/get-kali/#kali-virtual-machines)

다운로드한 파일의 압축을 해제하고 내부에 있는 vmx파일을 vmware에서 open하면 칼리 리눅스 설
치가 완료됩니다.

![[Pasted image 20251212203923.png]]

칼리 리눅스를 부팅하고 로그인 창이 뜨면 기본 ID, Password를 입력합니다.

- ID: kali
- Password: kali

## DVWA 설치

이제 칼리 리눅스 상에 DVWA(Damn Vulnerable Web App)를 설치해야 합니다.

DVWA는 일부러 취약하게 만든 웹 환경으로 교육, 취약점 진단, 모의해킹 등의 목적으로 사용이 가능합니다.

![[Pasted image 20251212204022.png]]
![[Pasted image 20251212204025.png]]

칼리 리눅스의 터미널을 실행하여 `sudo su -` 명령어를 입력하여 ROOT 권한을 획득하고 Apache 웹 서버의 기본 웹 루트 디렉토리인 `/var/www/html`로 이동합니다.

이후 DVWA 깃허브 레포지토리에 접속합니다. 링크는 아래와 같습니다.
[digininja/DVWA: Damn Vulnerable Web Application (DVWA)](https://github.com/digininja/DVWA)

![[Pasted image 20251212204106.png]]

위 그림과 같이 녹색 Code버튼을 클릭 후 HTTPS의 URL을 복사합니다.

![[Pasted image 20251212204114.png]]

그리고 터미널에 `git clone [복사한 URL]`을 입력합니다.

![[Pasted image 20251212204126.png]]

이후 `sudo service apache2 start`로 Apache 웹 서버를 실행시킵니다.(관리자 모드로 접속했을 경우 sudo는 생략 가능합니다.)

![[Pasted image 20251212204144.png]]

이후 브라우저로 'http://localhost/' 에 접속해보고 위와 같은 페이지가 나오면 정상 작동하는 것입니다.

## DVWA 설정
![[Pasted image 20251212204204.png]]

DVWA 설정 파일을 생성하기 위해 현재 디렉토리에서 DVWA 디렉토리로 이동합니다.

![[Pasted image 20251212204216.png]]

이후 설정 예시 파일인 `config.inc.php.dist`를 이용하여 DVWA 설정 파일을 생성합니다. 명령어는 아래와 같습니다.
`cp config/config.inc.php.dist config/config.inc.php`

![[Pasted image 20251212204229.png]]

그리고 브라우저로 'http://localhost/DVWA/setup.php' 에 접속하여 Database를 생성해줍니다.

![[Pasted image 20251212204252.png]]

다시 터미널로 돌아와서 `service mariadb start` 명령어로 마리아 DB를 실행시킵니다.

![[Pasted image 20251212204258.png]]

`mysql`을 입력하여 DB에 접근합니다.

그리고 아래의 명령어를 차례대로 실행합니다.

```
// 데이터 베이스를 생성합니다.
create database dvwa;

// 사용자를 생성합니다.
create user dvwa@localhost identified by p@ssw0rd;

// 사용자에게 생성한 dvwa DB의 전체 권한을 부여합니다.
grant all on dvwa.* to dvwa@localhost;

// 변경사항을 적용합니다.
flush privileges;
```

### DVWA url include, 에러 기능 활성화
`/var/www/html/DVWA/etc/php/[설치된 php버전]/apache2` 디렉토리로 이동하여 PHP 설정 파일인 php.ini를 수정합니다.
`vim php.ini` 명령어로 vim 에디터를 통해 수정할 수 있으며 타 에디터를 사용하여도 무방합니다.

![[Pasted image 20251212204410.png]]

`php.ini`에서 `allow_url_include`, `display_errors`, `display_startup_error`의 값을 'Off'에서 'On'으로 변경합니다.
위 값들의 의미는 아래와 같습니다.
- **allow_url_include**: 원격 파일을 include, require하는 것을 허용할지 결정하는 항목입니다. File Inclusion 취약점 실습 시 필요합니다.
- **display_errors**: PHP 실행 중 발생한 오류를 브라우저 화면에 표시할지 결정하는 항목입니다.
- **display_startup_error**: PHP 시작 시점(초기화 단계)에 발생한 에러를 화면에 표시할지 결정하는 항목입니다.

![[Pasted image 20251212204425.png]]

`apachectl restart`로 Apache 웹 서버를 재시작하고 DVWA 웹을 새로고침 해보면 적용된 것을 확인할 수 있습니다.

### DVWA 업로드 디렉토리 권한 설정
파일 업로드 기능을 사용해야할 때 필요한 기능입니다.

아래의 코드를 차례대로 터미널에 입력합니다.

```
// 디렉토리의 소유자를 'www-data(Apache)'로 변경합니다.
chown www-data /var/www/html/DVWA/hackable/uploads

// 소유자가 잘 변경되었는지 확인합니다.
ls -al /var/www/html/DVWA/hackable/uploads

// 마찬가지로 소유자를 변경하고 확인합니다.
chown www-data /var/www/html/DVWA/config
ls -al /var/www/html/DVWA/config
```

### CAPTCHA 설정
DVWA의 취약한 캡차 탭을 사용하려면 php-gd 모듈을 설치하고 캡차 키를 발급받아 등록해야 합니다.

아래의 커맨드로 php-gd를 설치합니다.

```
apt update
apt install php-gd
apachectl restart
```

구글의 reCAPTCHA를 통해서 캡차 키를 발급받도록 하겠습니다.
[reCAPTCHA 웹사이트 보안 및 사기 방지 | Google Cloud](https://cloud.google.com/security/products/recaptcha)
위의 링크에 접속하여 구글 로그인을 합니다.

![[Pasted image 20251212204554.png]]

사진과 같이 설정하고 제출 버튼을 누릅니다.

![[Pasted image 20251212204613.png]]

캡차 키가 발급된 것을 확인할 수 있습니다.

이제 이 키를 php설정 파일에 등록해야 합니다. 칼리 리눅스로 돌아와서 php 설정 파일을 열어줍니다. 명령어는 하단과 같습니다.

```
cd /var/www/html/DVWA/config
vim config.inc.php
```

![[Pasted image 20251212204632.png]]

recaptcha 필드를 찾아 공개 키와 비밀 키를 설정하고 저장합니다.
