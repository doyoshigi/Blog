# 웹 모의해킹 보고서 DVWA(Medium) File Upload, CAPTCHA
DVWA의 Medium 난이도의 File Upload, CAPTCHA를 실습하고 취약점 분석, 시나리오, 공격 실습, 대응방안을 포함한 보고서를 작성했습니다. 

[보고서 링크](https://github.com/doyoshigi/refactoring-course-ai-school/blob/main/%EB%AA%A8%EC%9D%98%ED%95%B4%ED%82%B9%EB%B3%B4%EA%B3%A0%EC%84%9C/%EB%A6%AC%ED%8C%A9%ED%86%A0%EB%A7%81_42%EC%A3%BC%EC%B0%A8_%EB%AA%A8%EC%9D%98%ED%95%B4%ED%82%B9_%EB%B3%B4%EA%B3%A0%EC%84%9C_FileUpload_InsecureCAPTCHA.pdf)

## 작성 시 고려한 포인트
- 작성할 때 사진의 가시성을 위해 빨간색 테두리 박스를 표시했습니다.
- 어려운 단어를 쉽게 풀어서 설명하려고 했습니다.
- 지난 보고서에서 미흡했던 대응방안의 구체성을 높혔습니다.
- 지난 보고서에서 미흡했던 시나리오의 수를 2개로 늘렸습니다.

## 추후 실무에서 고려할 점
- 실무에서는 회사의 OS에 맞는 대응방안을 작성해야 합니다.
- 대응방안은 실제 법령과 가이드에서 요구하는 수준으로 제시되어야 합니다.
