**웹 쉘(Web Shell)**
- 웹 서버에 업로드된 원격 명령 실행용 스크립트이다.
- 공격자가 지속적으로 서버를 조종할 수 있게 해주는 백도어 역할을 한다.
- php, jsp, asp 등 서버 사이드 스크립트 언어로 작성되며 공격자는 웹 서버의 취약점을 이용하여 웹 쉘을 서버에 삽입한다. (보통 파일 업로드 취약점을 노린다.)

**특징**
- 공격자가 웹 쉘을 통해 서버에 명령을 보낼 때도 일반적인 웹 요청처럼 보여 정상적인 웹 트래픽으로 오인하기 쉽다.
	- 탐지패턴을 통해서 탐지가 가능하다.
- 정상 파일로 위장될 수 있다.(GIF, PNG, JPEG, JPG 등)
