**악성코드 탐지 구분**
악성코드를 탐지하는 것을 정탐, 오탐, 미탐으로 구분한다.


|       | Positive       | Negative       |
| ----- | -------------- | -------------- |
| True  | True Positive  | True Negavite  |
| False | False Positive | False Negative |
Positive: 탐지 시스템이 공격이라고 판단하여 알림/차단이 발생
Negative: 탐지 시스템이 정상이라고 판단하여 알림/차단이 발생하지 않음

True: 실제와 판단이 일치
False: 실제와 판단이 불일치

**정탐(True Positive)**
- 공격이 있었고 공격으로 탐지한 경우(제대로 탐지)

**오탐(False Positive)**
- 공격이 없었고 공격으로 탐지한 경우(잘못 탐지)

**미탐(False Negative)**
- 공격이 있었고 공격을 탐지하지 못한 경우(침입 허용)
- 미탐을 최대한 줄이는 것이 중요하다.
