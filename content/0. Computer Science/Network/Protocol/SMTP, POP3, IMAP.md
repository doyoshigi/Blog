SMTP는 이메일을 전송하기 위해, POP3, IMAP은 서버에서 메일을 가져오기 위한 TCP 기반 애플리케이션 계층 프로토콜이다.

**SMTP(Simple Mail Transfer Protocol)**
- 이메일 클라이언트에서 메일 서버로, 서버와 서버 간에 이메일을 전송하고 중계하기 위해 사용하는 프로토콜이다.
- **포트**
	- 25/TCP: 서버와 서버 간 전달
	- 587/TCP: 클라이언트에서 서버로 메일 제출
	- 465/TCP: TLS로 암호화하여 클라이언트에서 서버로 메일 제출

**POP3(Post Office Protocol version 3)**
- 이메일 클라이언트가 메일 서버에서 이메일을 가져오기 위해 사용하는 프로토콜이다.
- 메일을 다운로드한 후, 서버에서 삭제하여 로컬 기기에서만 확인 가능하게 한다.
- **포트**
	- 110/TCP: 평문 POP3 접속 포트
	- 995/TCP: TLS로 암호화된 POP3 접속 포트

**IMAP(Internet Message Access Protocol)**
- 여러 장치에서 이메일을 관리하고 동기화하기 위해 사용되는 프로토콜이다.
- 이메일이 서버에 저장되고 클라이언트는 서버의 복사본을 보여주는 방식으로 작동한다. 모든 기기에서 동일한 메일 상태를 유지하게 해준다.
- 관리가 편리하다.
- **포트**
	- 143/TCP: 평문 IMAP 접속 포트
	- 993/TCP: TLS로 암호화된 IMAP 접속 포트

**보안 관점에서 POP3, IMAP 차이**
- IMAP은 메일 서버가 공격 당한 경우 모든 메일이 노출될 가능성이 있다.

**서버 부하 관점에서 POP3, IMAP 차이**
- **IMAP**
	- IMAP은 메일이 서버에 계속 저장되어 있기 때문에 저장 부담이 크다.
	- 여러 기기 동기화로 관리 부담이 크다.
- **POP3**
	- 다운로드 후 삭제하기 때문에 저장 부담이 적다.
