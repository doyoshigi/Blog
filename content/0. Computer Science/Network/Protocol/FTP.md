**FTP**
- FTP(File Transfer Protocol)은 파일 전송용 애플리케이션 계층 프로토콜로, TCP 기반 프로토콜이다.
- 2개(제어 채널, 데이터 채널)의 TCP 연결이 필요하다. 
- Active 모드, Passive 모드 2가지가 존재한다.
- 기본적으로 암호화가 없다.(FTPS로 암호화)

- **제어 채널(Control Channel)**
	- 명령/응답 전용 통로이다.
	- 세션 동안 계속 연결이 유지된다.
	- 서버는 TCP 21번 포트에서 제어 채널을 항상 대기한다.
	- 클라이언트는 보통 임시포트를 사용하여 서버에 연결한다.
- **데이터 채널(Data Channel)** 
	- 실제 데이터가 전송되는 통로이다.
	- 보통 전송이 필요할 때만 열렸다가 전송이 끝나면 닫힌다.
	- 데이터 채널 연결 모드는 능동 모드와 수동 모드가 있다.

- **Active(능동) 모드(20/TCP)**
	- 서버가 클라이언트로 데이터 채널 연결을 걸어오는 방식이다.
	- **흐름**
		1. 클라이언트가 서버와 제어 채널을 연결한다.
		2. 클라이언트가 자기쪽 임시 포트를 하나 열어두고, 서버에게 제어 채널로 알린다.
		3. 서버가 데이터 채널을 서버 20번 포트에서 출발해서 클라이언트가 열어둔 포트로 연결한다.
- **Passive(수동) 모드 (임의의 포트/TCP)**
	 - 클라이언트가 서버가 열어준 데이터 포트로 접속하는 방식이다.
	 - **흐름**
		 1. 클라이언트가 서버와 제어 채널을 연결한다.
		 2. 클라이언트가 서버에게 데이터 포트를 요청한다.
		 3. 서버가 임시 포트를 하나 열고 클라이언트에게 제어 채널로 알린다.
		 4. 클라이언트가 그 포트로 데이터 채널을 연결한다.

- 능동 모드는 서버가 클라이언트에 데이터 채널 요청을 해야하기 때문에 클라이언트가 NAT이나 방화벽 뒤에 있다면 잘 막힌다.
- 수동 모드는 클라이언트가 서버에 데이터 채널 요청을 해야하기 때문에 클라이언트가 NAT이나 방화벽 뒤에 있는 상황에서 잘 전달된다.
