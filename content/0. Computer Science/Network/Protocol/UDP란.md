## UDP(User Datagram Protocol)
UDP는 트렌스포트 계층 프로토콜로, 애플리케이션에 간단하고 빠른 데이터그램(datagram) 전송을 제공한다.

## 특징
**1. 비연결**
- 연결 수립 과정이 없고 보내고 싶을 때 바로 전송한다.
- 커널이 연결상태를 유지하지 않아서 구현, 처리가 단순하다.

**2. 신뢰성 보장X**
- 데이터그램이 유실/중복/순서 변경될 수 있고, UDP는 이를 복구하지 않는다.

**3. 메시지 경계 유지**
- 데이터그램 단위로 전송한다.
- 송신이 보낸 1개 데이터그램은 수신에도 1개 단위로 전달된다(합쳐지지 않음).

**4. 오버헤드가 작고 지연이 낮다**
- 헤더가 8바이트로 단순하고, 연결/재전송/윈도우 같은 관리가 없어서 일반적으로 지연이 낮고 가볍다.

## 헤더 구조
![[Pasted image 20251227204810.png]]

UDP 헤더는 고정 8Byte로 매우 단순하다.

- **Source/Destination Port:** 어떤 프로세스로 보내는지 구분한다. (포트 기반 다중화)
- **Length:** UDP헤더 + 데이터 전체 길이(바이트)
- **Checksum:** 전송 중 오류 검출
	- 오류가 검출되어도 재전송을 요청하지는 않는다.
	- IPv6에서는 UDP 체크섬이 필수, IPv4에서는 0으로 비활성화 가능(상황에 따라).
