## TCP, UDP 차이점

| 비교        | TCP                                                      | UDP                                               |
| --------- | -------------------------------------------------------- | ------------------------------------------------- |
| 헤더 크기     | 20Byte~60Byte                                            | 8Byte                                             |
| 연결 방식     | 연결 지향(연결 수립: 3-way, 종료: 4-way)<br>양쪽 OS에 연결 상태 생성/유지     | 비연결<br>상태 유지 없음                                   |
| 신뢰성       | 신뢰성 제공<br>Seq, Ack으로 데이터 전달 확인<br>손실 시 재전송(타임아웃, 중복 ACK) | 신뢰성 제공하지 않음<br>손실/중복/순서 변경 가능<br>체크섬 오류면 데이터그램 드롭 |
| 순서 보장     | 순서 보장<br>바이트 스트림 기반 시퀀스 번호로 재조립                          | 순서 보장 X<br>도착한 순서대로 혹은 섞여서 받을 수 있음                |
| 데이터 전달 형태 | 바이트 스트림(메시지 경계 x)                                        | 데이터그램(메시지 경계 O)                                   |
| 전송률 조절    | 흐름 제어, 혼잡 제어로 전송량을 조절                                    | 전송률 조절 x                                          |
| 오버헤드      | 오버헤드가 큼                                                  | 오버헤드가 작음                                          |
TCP는 연결을 맺고 상태를 유지하면서 신뢰성/순서/흐름·혼잡제어를 제공하는 바이트스트림이고, UDP는 연결없이 데이터그램을 전송하며 신뢰성/순서/흐름·혼잡제어를 제공하지 않는 프로토콜이다.
