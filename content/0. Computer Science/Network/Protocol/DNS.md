**DNS(Domain Name System)**
- DNS는 도메인 이름을  IP주소로 변환해주는 애플리케이션 계층 프로토콜/시스템이다. 
- 재귀 서버(Local DNS server), 권한 서버(Authoritative DNS server)로 구성되어 있다.
	- 재귀서버는 최종 사용자를 대신하여 도메인 이름을 IP 주소로 변환해주고 캐시한다.
	- 권한 서버는 도메인에 대한 최종 레코드를 보유하고 도메인 이름에 대한 요청을 응답한다.
- **흐름**
	- 클라이언트 -> 재귀 서버 -> (캐시에 없다면) 루트 DNS 서버 -> TLD서버 -> 권한 서버 -> 재귀 서버 캐시 -> 클라이언트
- **프로토콜**
	- DNS는 UDP, TCP를 둘다 사용하고 포트는 53번이다.
	- 일반적인 질의/응답에는 오버헤드가 작은 UDP를 사용한다.
	- 응답이 너무 크거나 특정 상황에서 TCP를 사용한다.
- **레코드**
	- A: 도메인 이름 -> IPv4 주소
	- AAAA: 도메인 이름 -> IPv6 주소
	- CNAME: 도메인 이름 -> 별칭(다른 도메인 이름)
	- MX: 도메인 이름 -> 메일 서버 도메인 이름
	- NS: 도메인 이름 -> 권한 서버 도메인 이름
	- TXT: 도메인 이름 -> 도메인에 대한 임의의 텍스트 정보

**공격 유형**
- **DNS 스푸핑/캐시 포이즈닝:** DNS 응답을 속여서 악성 사이트로 유도
- **DDoS 공격:** 작은 요청을 보내 큰 응답을 유도하고 출발지 IP를 피해자로 위조해 공격 트래픽을 피해자에게 몰아준다.
- **DNS 터널링:** DNS 질의/응답에 데이터를 숨겨서 명령 전달이나 정보 유출 통로로 사용
- **타이포스쿼팅:** 비슷한 도메인을 등록해 피싱 유도
