**Proxy**
- 프록시는 클라이언트와 서버 사이에서 대신 통신해주는 중계 서버이다.
- 프록시 서버를 앞에 둬서 내부 서버를 보호할 수 있다.
- 프록시 서버만 노출을 시켜서 내부 서버를 보호할 수 있도록 한다.
- 접근 제어, 보안 강화 기능도 사용할 수 있다.

**프록시 유형**
- 프록시 서버의 위치에 따라 Forward Proxy, Reverse Proxy로 나눌 수 있다.
- **Forward Proxy**
	- 클라이언트(사용자) 앞단에 놓여서, 사용자의 요청을 대신 전달하고 그 결과를 돌려준다.(일반적인 프록시 형태)
	- 사내 인터넷 사용 통제(유해 사이트 차단, 업무 사이트만 허용), 사용자별 접속 로그 검사, 외부로 나가는 트래픽에 대한 보안 검사
	- 내부 사용자 IP 직접 노출 x
- **Reverse Proxy**
	- 서버 앞단에 놓여서, 외부 사용자의 요청을 서버 대신 받아주고 서버로 전달한다.
	- 로드 밸런싱, 보안(비정상 요청 차단)
	- 내부 서버 IP 직접 노출 x
